# Riesgo de liquidez

Presentación interactiva de 2 diapositivas sobre **riesgo inherente de liquidez, perfil de fondeo y herramientas de control**.

## Contenido
1. **Riesgo inherente de liquidez y perfil de fondeo**: definición, diferencia entre liquidez y riesgo de liquidez, y comparación de fondeo minorista y mayorista.
2. **Herramientas de control**: flujo de caja, análisis de brechas, pruebas de estrés, plan de contingencia y capacidad de balanceo.

## Cómo verla
Abre `index.html` en el navegador o visita la página publicada con GitHub Pages.

- Navegación: botones, flechas del teclado o deslizar en el celular.
- Interacción: alternar Minorista / Mayorista y tocar las herramientas de control para ver su detalle.
